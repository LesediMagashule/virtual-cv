# Virtual CV

Welcome to my Virtual CV repository! This project is an interactive, responsive personal portfolio website developed as part of my university coursework.

## 🚀 Live Demo
Once deployed on GitHub Pages, add your URL here:
`https://LesediMagashule.github.io/virtual-cv`

## 📌 Features
- **About Me:** Professional overview and background.
- **Resume/CV:** Direct link to view and download CV.
- **Technical Skills:** Highlights key tools and languages.
- **Projects:** Interactive cards with links to GitHub repositories.
- **Contact Form:** Interactive form for reaching out.

## 🛠️ Technologies Used
- **HTML5:** Semantic structure
- **CSS3:** Responsive layout and styling
- **JavaScript:** DOM manipulation and interactive features
- **Git & GitHub:** Version control and GitHub Pages hosting
